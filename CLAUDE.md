# Пульк — инструкция проекта

Пульк — бесплатная клавиатура-звезда для набора одним большим пальцем и «Говорить» для тех, кто может двигаться, но не говорить. Для людей с моторными, нейро- и сенсорными особенностями и для всех, кто печатает одной рукой. Без монетизации и без сбора данных.

## Две версии — одна правда
- **Android** — эта папка `G:\DEV\projects\pulk` (Kotlin без библиотек). Системная клавиатура для всех приложений.
- **Веб** — `G:\DEV\projects\pulk\web` в этом же репозитории (core.js — ядро, app.js — страница). Для iPhone, печатает внутри страницы. Сайт Дуги забирает эту папку сам при каждой публикации — в Дуге веба больше нет, правь только здесь.
- Общие данные (буквы звезды, фразы, тренировки, пруд) живут в Kotlin и переносятся в веб: `node tools/build-web.js` здесь.
- Сайт: https://danyapole.github.io/duga/pulk/ (скачивание, таблица «Android или браузер», инструкции родителю/пользователю/педагогу из `G:\DEV\projects\duga\tools\make-guides.js`).

## Как работаем
- Автор — художник, не программист, пишет по-русски. Объяснять просто, давать варианты и свой совет; «газ» = делай по своему совету.
- В начале каждого этапа называть модель и усилие: Opus высокое — жесты, архитектура, доступность, педагогика, проверки; Opus низкое — экраны, тексты, сборка, публикация.
- Каждое изменение — в обе версии (или явная причина, почему в одну). По одному изменению за раз: тесты → коммит → дальше.
- После шага: Android-тесты, веб-тесты, прогон экранов в браузере; честно говорить, что проверено, а что нет.
- Вместе с функциями обновлять таблицу «Android или браузер» (`G:\DEV\projects\duga\pulk\index.html`, id="diff") и инструкции.
- Предупреждать, когда пора начать новый сеанс (этап сохранён, переписка длинная или впереди большая задача).
- Идеи на потом — в `G:\DEV\projects\duga\IDEAS.md`, не делать без решения автора.

## Принципы продукта (не нарушать)
- У приложения нет доступа к интернету (в манифесте только VIBRATE); голоса — только встроенные; данные на устройстве.
- Пароли: без звука, голоса, подсказок и обучения слов.
- Обучение без оценок: «ошибиться невозможно», не та буква не печатается, после трёх попыток Пульк помогает.
- Вопросы о человеке — про трудности, не про диагнозы; «Не знаю» всегда безопасно.
- Никаких действий по таймеру по умолчанию; ничего не меняется молча — только предлагается.
- Для проектирования и проверки экранов — скил `inclusive-product`.
