# Записи движений (Android)

Включение: «Настройки → Ещё → Помочь улучшить Пульк». По умолчанию выключено.
Записываются только движения к известной букве в уроках и «Пузырях»; свободные ответы в тренировках не записываются: их цель неизвестна.
Отправка — только выбранным человеком приложением через системное «Поделиться».
«Стереть все движения» обнуляет записи и копию для отправки. Уже отправленный чужому приложению файл Пульк стереть не может.
Новая отправка получает отдельный файл и адрес; предыдущая копия обнуляется. Старое разрешение не открывает новые записи.
Лимит 5 МиБ, без автоматического удаления старых записей. Обычный набор и защищённые поля исключены.

JSON Lines: первая строка — `schema=pulk-traces`, `version=1`.
Одна следующая строка — один смах или толчок к одной заданной букве (в «Лепестках» — номер лепестка).
Нет набранных слов, абсолютных координат, часов, имён и идентификаторов.
`points`: `[x,y,t]`, dp относительно начала смаха/толчка, оси экрана (вправо/вниз), время от его начала в мс.
Это **вход распознавателя после сглаживания**, не сырые события датчика; для повторного разбора сглаживание не применяется второй раз.
`tol` и `scaleDp` позволяют восстановить базовые единицы; `bias` — угловая калибровка.
Точки отрыва, отсечённые клавиатурой, уже отсечены в записи. Касания без смаха и служебные клавиши пропускаются.
`recognized` — результат распознавания до учебной помощи.

Повтор без сети, через текущие `Pulse.resolve/jab/jabPetal` (PowerShell):

```powershell
$env:PULK_TRACES = 'C:\путь\pulk-traces.jsonl'
powershell -NoProfile -File gw.ps1 testDebugUnitTest --tests app.pulk.TraceReplayTest
```

Вывод: `traces pulse/jabs/petals: верно/всего = доля`. Сами движения в лог не выводятся.
Образец: `tests/fixtures/gesture-traces.jsonl` (синтетический; одна намеренно несовпавшая цель).
Веб-записи не добавлены: приватное хранение и выдача файла в браузере требуют отдельной реализации; T3 разрешает ограничиться Android.
