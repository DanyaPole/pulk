# Пульк — интерфейс приложения: итог

- **Экраны (холст Design):** https://claude.ai/artifact/BbejfooJyETyVpVeVDwtdr — 11 экранов с размерами в dp, в цветах дизайн-системы «Пульк» (светлая тема), звезда на макетах уроков посчитана по геометрии `Pulse.kt`.
- **Полный текстовый проект:** [docs/UX-PROJECT.md](docs/UX-PROJECT.md) (карта экранов, жесты и путаницы, ошибки без вины, подсказки, доступность по группам, простой режим, план проверки на людях).
- **Где правила изменились позже** (верен CLAUDE.md): помощь в обучении — после трёх попыток, не двух; не та буква в уроке не печатается («ошибиться невозможно»), поэтому строку «Вышло „н“» читать как подсказку без набранной буквы.
- Размеры на холсте — для телефона 412 × 892 dp (как у дизайн-системы), 1 px макета = 1 dp. В UX-PROJECT.md те же экраны описаны для 360 × 800; где они расходятся, верен холст.

## Согласовано с пользователем
1. Главная + разделы (Обучение, Под мою руку, Настройки → Ещё) вместо одного длинного списка.
2. Сложные жесты открываются постепенно: после урока — карточка «Новое: … Включить?»; «Включить всё» — в «Ещё → Новые жесты».
3. При первом запуске вопрос «Что тебе поможет?» (рука дрожит / трудно смахивать / плохо вижу / хочу попроще); его можно пропустить.

## Ключевые решения
- **Приложение тоже под один палец:** нажимаемое — ниже ~360 dp, главная кнопка 64 dp внизу, «Назад» внизу (не в верхнем углу). Сверху только текст.
- **Мастер первого запуска, 5 шагов:** П1 Рука (две половины экрана 182 × 456) → П1б Что поможет → П2 Включить → П3 Выбрать → П4 Настройка под руку (можно «Позже») → П5 Первое слово «он» (только крупные буквы, подсказка прямо на звезде). Когда человек возвращается из системных настроек, приложение само проверяет шаг.
- **Итог калибровки «Что мы подстроили»:** у каждой строки свой переключатель; если смахи даются тяжело — совет «Два касания».
- **Шаг урока:** кнопки «Подсказать / Послушать / Ещё» стоят полосой 56 dp прямо над клавиатурой; «Меню» уходит в «Ещё». Промах — нейтральная строка «Вышло „н“. Ещё раз — без спешки», после двух промахов — карточка «Показать, как? Да / Не сейчас».
- **Одно правило отмены:** ⌫ сразу после любого действия клавиатуры отменяет это действие.
- **Ничего только цветом:** выбранное = заливка + галочка/рамка, шаги = точки разной формы + «Шаг N из 5».
- **Простой режим:** буквы, пробел, ⌫, ⏎, спрятать, ?123, одна подсказка; без смахов по пробелу, курсора, автоисправления и следующего слова.

## Что перенести в код первым
1. Перенести нажимаемое вниз: «← Меню» в `TutorialActivity` → полоса кнопок над клавиатурой; главные кнопки внизу на всех экранах.
2. Мастер первого запуска (П1–П5) с проверкой «включено / выбрано» в `onResume` (`InputMethodManager.enabledInputMethodList`, `Settings.Secure.DEFAULT_INPUT_METHOD`).
3. Разбить `SettingsActivity` на Главную, Основные настройки и «Ещё» (группы по ≤ 5 пунктов).
4. Правило «⌫ сразу после = отменить» для стёртого слова, взятой подсказки и пробела от поднятого пальца в «Толчках» (сейчас так работает только автоисправление).
5. Экран итога калибровки «Что мы подстроили» + совет «Два касания».
6. Простой режим (`Prefs.simple`) и постепенное включение жестов (`Prefs` — набор включённых жестов).

Не нарисованы (описаны текстом): подэкраны групп «Ещё», тёмная тема, левая рука (зеркально), экран итога урока.
