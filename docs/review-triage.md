## F-001 — ключ подписи

- В git ключа **нет**: `keys/` в `.gitignore`, в индексе git Пулька (111 файлов) его нет, в истории репозитория duga на GitHub тоже нет.
- Но архив для рецензентов собран **вручную из всей папки** (скрипта для архива в проекте нет) — вместе с `.git`, `build/` и `keys/`.
- В `keys/keystore.properties` пароли от ключа лежат открытым текстом. Значит, у тех, кто получил архив, есть и ключ, и пароли.
- Чем опасно: с этим ключом можно сделать поддельный «Пульк», и Android примет его как обычное обновление настоящего. Клавиатура видит всё, что человек печатает, поэтому риск серьёзный, хоть и маловероятный.
- Цена замены: старые установки не смогут обновиться — Пульк придётся удалить и поставить заново, данные на телефоне (свои слова, фразы) пропадут. Сейчас установок почти нет, поэтому **дешевле всего заменить ключ до пятничной пробы**.
- Ещё: удалить архив с диска и из чатов, куда его загружали; если эти пароли где-то ещё используются — сменить их там.
