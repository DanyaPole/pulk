# Пульк

Клавиатура для Android для набора одной рукой, большим пальцем. Режим «Пульс» из веб-демо
[Дуга](https://danyapole.github.io/duga/): все буквы в звезде из 8 направлений.

- Прямой смах — крупная буква, смах с поворотом — мелкая снаружи, «туда и обратно» — мелкая у центра, касание в центре — пробел.
- Подсказки слов над звездой (лучшая ближе к пальцу), смах по пробелу вверх вдоль дуги — взять лучшую.
- Автоисправление с учётом типичных промахов «Пульса»; ⌫ сразу после — вернуть своё слово.
- Вибрация, щелчки с нотой на каждое направление, голос, режим «вслепую», левая рука.
- Обучение из 4 уровней с подсказками прямо на звезде.
- Нет доступа к интернету: в приложении только разрешение на вибрацию.

## Сборка

Инструменты в `C:\Android` (JDK 17, Android SDK 34). `.\gw.ps1 testDebugUnitTest assembleRelease`.
Ключ подписи в `keys/` (не в git). Без него релизная сборка не подписывается.
