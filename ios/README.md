# Пульк для iPhone (системная клавиатура)

Сборка — в облаке GitHub (Mac не нужен): `.github/workflows/ios.yml`, запуск вручную.

1. GitHub → Actions → iOS → Run workflow.
2. Когда готово, скачай артефакт `Pulk-unsigned`, распакуй — внутри `Pulk-unsigned.ipa`.
3. На Windows: Sideloadly → подключи iPhone → выбери ipa → войди в Apple ID → Start.
4. iPhone: Настройки → Конфиденциальность и безопасность → Режим разработчика → включить (перезагрузка).
5. Настройки → Основные → VPN и управление устройством → доверять своему Apple ID.
6. Настройки → Основные → Клавиатура → Клавиатуры → Новая клавиатура → Пульк.

Бесплатная подпись живёт 7 дней — потом ставить заново тем же способом.
Доступ в сеть и «Полный доступ» клавиатуре не нужны и не запрашиваются.
